# 전문 크리에이터 핵심 작업 흐름 고도화

2026-10-09 · Codex / Claude 공동 구현. 기존 checkout의 변경이며 배포·커밋·푸시는 하지 않았다.
Claude는 사용자가 지정한 `term_12622c08-9f8a-4958-9439-c2c9f11e477c`에서 인박스/댓글/AI 초안을,
Codex는 예약·성과·만들기 보호·매뉴얼·교차 검토와 통합 검증을 맡았다.

## 구현

- **예약 운영:** 주간/월간/목록 보기와 URL `view` 보존, 검색·플랫폼·상태 필터,
  플랫폼/연결 계정별 시간 편집, 대기 예약 선택·일괄 이동/취소, 확인 단계, 항목별 실패와 실패만 재선택.
  기존 예약 API를 호출하고 성공 응답만 반영한다. 완료/실행 중 작업은 편집하지 않는다.
  전체 이동은 계정별 시간 차이를 유지하며, 서버가 각 대상의 과거 시간·플랜 허용 기간을 재검증한다.
  브라우저의 DST가 한국 시간 일괄 이동을 바꾸지 않으며, 월초가 이전 주에 속해도 현재 월을 연다.
- **외부 일정:** 필터 결과를 계정별 실제 게시 시각으로 `.ics` 내보내기. UTC 시각·고유 UID·한글 75바이트 줄 접기.
  단방향 스냅샷이며 외부 캘린더 수정은 onGo에 반영되지 않는다.
- **성과 작업대:** 실제 플랫폼별 조회수/좋아요/댓글/공유, 태그별 평균·좋아요 비율·표본 수·추세,
  이력 기반 추천 시각에서 미래 KST 예약을 채운 만들기로 이동, 영상 2~5개를 같은 기간으로 비교.
  이전 화면의 잘못된 "각 플랫폼에 크로스플랫폼 조회수 총합을 반복 합산"을 제거했다.
  미측정은 0과 구분하고, 참여율이 일부 지표만 반영할 때 표시한다.
  기간 전환 시 이전 값 제거, 느린 이전 응답 무시, 부분 실패/재조회/플랜 적용 기간 표시.
  CSV에 추이·인기 영상·플랫폼 집계를 포함하고 한글 BOM 및 수식으로 해석될 수 있는 제목을 처리한다.
- **만들기 보호:** 서버가 인정한 초안 스냅샷과 현재 편집을 비교한다. 이탈 시 저장/계속 편집/저장하지 않고 이동,
  새로고침 경고, 저장 실패 시 페이지 유지, 저장 중 추가 편집은 미저장으로 유지한다.
  업로드/저장/게시 실행 중 이탈을 막는다. 업로드되지 않은 파일·예약 설정은 메타데이터 초안 저장 대상이 아님을 안내한다.
  원본 접수 후 반복 게시/쇼츠 같은 추가 작업이 실패해도 원본을 다시 제출하지 않으며 접수된 영상으로 확인한다.
- **인박스:** Claude 구현/검증 내용은 [공동 작업 보고서](creator-pro-claude-report.md)에 기록한다.
  교차 검토에서 실패 재시도의 다른 배치 혼입, 부분 환불 이후 실제 AI 원가 예산 유지,
  환불 실패 시 최종 차감량 오표시, 서버 감정 필터/검색 요청 역전 문제를 확인해 Claude에 수정 요청했다.
- **도움말:** `components/manual/manualSections.ts`의 한국어/영어 실제 사용 설명 갱신 및 인박스 출시 capability 등록.

## 최종 검증

- 프론트 전체: 155개 파일, 1,321개 테스트 통과. 양측 최종 수정 이후 `npm test` 실행.
- 프론트 프로덕션 빌드(`vue-tsc -b && vite build`) 통과. `npm run lint`: 오류 0개, 경고 246개(기존 코드 경고 포함).
- 백엔드 application 2,108개 및 API 175개 테스트 통과: 실패·오류·건너뛰기 모두 0.
  `./backend/gradlew -p backend :onGo-application:test :onGo-api:test --no-daemon` 성공.
  실제 임시 PostgreSQL 컨테이너를 사용하는 Spring 컨텍스트 smoke 테스트도 통과.
- 예약 백엔드 회귀 테스트 통과: 과거/플랜 초과 플랫폼 시간을 큐 변경 전에 거부.
- ego-browser에서 실제 Vue 컴포넌트를 별도 임시 fixture 화면으로 검증:
  목록/검색 → 플랫폼 시간 저장 → 일괄 취소 확인/실행, 영상 선택 비교, 모바일 캘린더/성과,
  초안 이탈 경고 → 서버 저장 응답 후 이동. 390px에서 캘린더와 성과의 전체 가로 넘침 없음.
  fixture는 실제 SNS API나 저장소를 호출하지 않는다. 임시 QA 파일은 제거하고 브라우저 작업 공간은 종료했다.
- 최초 백엔드 검증의 Docker 엔진 미실행 및 양측 Gradle 리포트 동시 쓰기 충돌은 로컬 Docker 기동 후
  최종 직렬 실행으로 해결했다. 최종 결과는 새로 생성된 JUnit XML 합계와 Gradle 성공 결과로 확인했다.
- `git diff --check` 통과.

## 범위

실제 OAuth/SNS 게시, 유료 AI 호출, 운영 DB/서비스, 배포는 실행하지 않았다.
테스트는 항목별 저장·권한·크레딧·실패 처리와 화면 동작을 검증한다. 외부 제공자의 실제 동작은 별도 운영 확인이 필요하다.
기존 사용자 파일 `설정_작업.txt`는 수정하지 않았다. iOS 시뮬레이터를 생성하지 않았다.
