
  1. 🚨 Git 히스토리에서 민감정보 완전 제거 (즉시)
  ────────────────────────────────────────────────
  .env.production과 restore_remote_db.sh의 과거 버전이 Git 커밋 히스토리에 영구 보관되어 있습니다.
  단순 삭제로는 부족하며, git filter-repo로 히스토리를 재작성해야 합니다.

  # 1. 설치
  brew install git-filter-repo

  # 2. 민감 문자열 일괄 교체 (프로젝트 루트에서 실행)
  cd /Users/bumkyuchun/work/app/ongo

  cat > /tmp/sensitive-replacements.txt << 'EOF'
  aaaAAA111!!!==>REDACTED_PASSWORD_CHANGE_ME
  minioadmin==>REDACTED_MINIO_CHANGE_ME
  pdl_ntfset_test_secret==>REDACTED_PADDLE_CHANGE_ME
  dummy-toss-secret==>REDACTED_TOSS_CHANGE_ME
  test_paddle_api_key==>REDACTED_PADDLE_API_CHANGE_ME
  test_paddle_client_token==>REDACTED_PADDLE_CLIENT_CHANGE_ME
  ongo_password==>REDACTED_DEV_PASSWORD_CHANGE_ME
  ongo-dev-jwt-secret-key-must-be-at-least-32-bytes-long==>REDACTED_DEV_JWT_CHANGE_ME
  Y2hhbmdlLW1lLXRvLWEtc2VjdXJlLXNlY3JldC1rZXk==>REDACTED_ENC_KEY_CHANGE_ME
  b25nby1kZXYtYWVzMjU2LWVuY3J5cHRpb24ta2V5MDA==>REDACTED_DEV_ENC_KEY_CHANGE_ME
  dummy-anthropic-key==>REDACTED_ANTHROPIC_CHANGE_ME
  dummy-openai-key==>REDACTED_OPENAI_CHANGE_ME
  dummy-google-api==>REDACTED_GOOGLE_API_CHANGE_ME
  EOF

  git filter-repo --replace-text /tmp/sensitive-replacements.txt --force

  # 3. remote에 강제 푸시 (협업자가 있다면 반드시 사전 공지)
  git push origin --force --all
  git push origin --force --tags

  ▌ ⚠️ 주의: git filter-repo는 모든 브랜치/태그를 재작성합니다. 팀원이 있다면 로컬 브랜치를 모두 삭제 후 재클론해야 합니다.
